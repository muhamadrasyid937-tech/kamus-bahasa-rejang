PANDUAN MENAMBAHKAN FITUR AKSARA TRACE

Isi perubahan:
- index.html: menambahkan tombol menu "Aksara Trace". Fitur kamus yang lain tetap dipertahankan.
- trace.html: halaman latihan aksara Kaganga dengan pola samar, input sentuhan/mouse, tombol hapus/periksa/sebelumnya/acak/berikutnya, skor perkiraan, dan progres lokal.
- sw.js: menaikkan versi cache dan memasukkan trace.html ke cache awal agar tersedia offline.

CARA MEMASANG DI GITHUB
1. Buka repositori GitHub yang menerbitkan website kamu (branch main, folder / root).
2. Klik Add file > Upload files.
3. Unggah tiga file: index.html, trace.html, dan sw.js dari paket ini. index.html dan sw.js akan menggantikan versi lama; trace.html menjadi file baru.
4. Pastikan ketiganya berada sejajar di folder utama/repositori (root), bukan dalam subfolder.
5. Buat SATU commit untuk ketiga file sekaligus, misalnya dengan pesan: Tambah fitur Aksara Trace.
6. Tunggu GitHub Pages selesai menerbitkan perubahan.
7. Buka website saat online, masuk ke Aksara Trace, dan coba gambar serta tombol "Cek latihan" sekali agar font yang dipakai juga sempat dimuat dan disimpan.
8. Tutup website, aktifkan mode pesawat, lalu buka aplikasi PWA lagi. Uji halaman Aksara Trace.

PENTING
- Jangan mengunggah ZIP ini sebagai satu file ke repositori. Ekstrak ZIP lalu unggah tiga file yang disebutkan.
- Jangan hapus atau mengganti manifest.json, folder icons, data, atau locale. Fitur lama tetap menggunakan file-file tersebut.
- Cache service worker harus diperbarui bersama trace.html karena versi cache baru memasukkan halaman trace ke cache awal.
- Progres latihan hanya tersimpan di browser/perangkat yang sedang dipakai; tidak tersinkron ke perangkat lain.
- Skor saat ini adalah perkiraan kedekatan goresan terhadap area huruf, bukan penilaian urutan goresan yang presisi.
