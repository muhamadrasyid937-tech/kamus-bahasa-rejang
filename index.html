🏛️ Aksara Kaganga — Warisan Leluhur Rejang

Aksara tradisional masyarakat Rejang, Bengkulu. Termasuk kelompok aksara Abugida — setiap konsonan mengandung bunyi vokal 'a' bawaan. Terdaftar dalam Unicode blok U+A930–U+A95F (2009).

🌿 Tentang Proyek

Kamus Bahasa Rejang & Aksara Kaganga adalah proyek open source untuk melestarikan Bahasa Rejang — bahasa daerah Bengkulu yang kaya. Tersedia dalam 1.500+ kata, 5 dialek, dan 3 bahasa (Indonesia, Inggris, Rejang).


🛠️ Struktur File

kamus-bahasa-rejang/
├── index.html                 ← Aplikasi web utama (buka langsung)
├── data/
│   ├── kosakata.json          ← ~320 kata kurasi, 5 dialek
│   ├── kosakata-berendo.json  ← 1.284 kata dari BERENDO resmi
│   └── kaganga.json           ← Data lengkap aksara Kaganga
├── locale/
│   ├── rej.json               ← Locale Rejang (Latin) untuk developer
│   ├── rej-Rjng.json          ← Locale Rejang (Kaganga)
│   ├── id.json                ← Locale Indonesia
│   ├── en.json                ← Locale English
│   └── README.md              ← Panduan integrasi i18n
├── berendo-extractor.js       ← Skrip ekstrak data BERENDO
├── package.json               ← Metadata npm
├── README.md
└── LICENSE
